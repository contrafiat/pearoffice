PearOffice 1.1.1 makes backing up to a seeder simpler.

## Improvements

- **A simpler Seeder screen.** Shorter instructions, and on phones one button to scan a seeder's QR code, with the option to paste a link instead
- **See what each seeder holds.** Each seeder now shows how many of your files back up to it
- **Clearer pairing.** Adding a seeder shows its progress and tells you plainly if something went wrong
- **Stop using a seeder faster.** It asks you to confirm, then finishes straight away. If someone else in a shared file added that seeder, you are told which files it keeps backing up
- **Get a seeder.** A new link takes you to the PeerLoom Seeder download page

## Bug Fixes

- Pairing a seeder again after you stopped using it now backs up your files to it again. Before, it backed up nothing

## Downloads

- **Linux:** the AppImage, or the .deb for Debian and Ubuntu
- **Mac:** the .dmg for Apple silicon (arm64) or Intel (x64)
- **Windows:** PearOffice-Setup. Windows may warn that the app is from an unknown publisher; choose More info, then Run anyway

The desktop app tells you when a new version is out.
