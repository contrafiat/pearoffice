# PearOffice seeder (now PeerLoom Seeder)

The PearOffice seeder is now **PeerLoom Seeder**, one seeder for every PeerLoom
app: https://peerloomllc.com/seeder/

This is the last PearOffice seeder download. It runs PeerLoom Seeder on your
existing data folder (`~/.pearoffice-seeder`, or `$PEAROFFICE_SEEDER_DATA`), so
your seeder, paired devices and stored files are kept and your devices need
nothing.

    ./pearoffice-seeder            run it
    ./pearoffice-seeder update     install the newest PeerLoom Seeder

Pair devices from the dashboard at http://127.0.0.1:8761 (open it on the
machine the seeder runs on). The systemd unit `pearoffice-seeder.service` keeps
working as before.

New install? Download PeerLoom Seeder from https://peerloomllc.com/seeder/
instead.
